# Approach

A Python batch CLI reads a data-only company config and runtime taxonomy, ingests all purchase rows, normalises signed decimal amounts/dates, removes gross-source VAT, converts to the reporting currency, applies eligibility, resolves entities, matches purchases, classifies included rows and exports the exact required schema. Every source row survives. Export validation replays accounting and matching rules; private diagnostics retain provenance and unresolved evidence.

Supplier/material IDs are scoped by source namespace. Unambiguous normalised names/descriptions anchor missing IDs; specifications remain distinct. Excluded rows cannot affect active alias or match evidence. Purchase matching uses bounded PO/invoice/supplier candidates, net reporting values, quantity and item evidence, constrained one-to-one capacity and explicit identity-conflict guards. ERP wins confirmed cross-source duplicates. Re-exports require a composite fingerprint. Ambiguous or split invoices stay included; conservative matching can overcount.

Classification retrieves exact runtime leaf paths through lexical token/character evidence or the pinned local LaBSE encoder. Full ancestor paths distinguish repeated leaves; unused levels remain blank. C needs only its config/raw file/tree, no labelled examples or learned artifact. Optional supervised word/character TF-IDF logistic regression uses supplied labels; unseen/OOV classes retain taxonomy retrieval. Vocabulary fitting follows grouped partition filtering; IDs/row order are not category features. Confidence is uncalibrated.

The genuine A labels-hidden run scored **12.10% exact path**, L1 **37.49%**, on 37,029 ERP labels; this is a material limitation. B zero-label exact accuracy was **35.88%** on 2,550 labelled paths. Optional supervised grouped development comparisons improved A item holdout **13.04→45.33%** and B source holdout **57.52→60.34%**. Baseline aggregates were already opened, so these are development results. Full-data submission fits have no held-out claim.

Three newly generated frozen synthetic seeds gave C exact accuracy **88.01% mean** (87.15–88.53%) and L1 **91.59%**; these self-authored scenarios are not an independent blind test. The 24-case adversarial audit passes after repairs. Stricter unchanged-config A replay retained 13 blank-evidence duplicates: precision 100%, recall 94.78%, spend overcount 3.56%.

On macOS/ARM64 CPU, Python 3.11.14, final A/B exports took **11.65/88.42 seconds** for 65,549/41,028 rows. A cold 25,000-distinct-evidence semantic run took **142.06 seconds**, including model startup but excluding installed model assets. Final training took **44.51/4.79 seconds**. Both official CSVs reproduced byte-for-byte; **79 tests passed**.

AI assistance supported coding; inference remains local. Paid API cost per 1,000 lines is **0**, with no keys or external purchase-text transmission. Inputs, derived reports and models stay ignored. Three B missing amounts and five absent invoice-month rates require flagged estimates; their true amounts remain unknown. B exclusion-label recall and real entity grouping remain limited.
